# Wordle Solver

## Overview

Wordle Solver is a C++ console application that helps users solve Wordle puzzles by narrowing down possible five-letter words based on clues provided by the user.

This project was developed as part of a Data Structures and Algorithms course at Washington Adventist University.

## Features

- Match words based on known letter positions
- Exclude words containing unwanted letters
- Include letters that must appear in the word
- Read candidate words from a dictionary file
- Display possible Wordle solutions based on user input

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Data Structures
- Standard Template Library (STL)
- File Input/Output (File I/O)

## How It Works

1. Enter the letters that are already known.
2. Enter letters that should be excluded.
3. Enter letters that must be included but whose positions are unknown.
4. The program filters the dictionary and displays matching words.
